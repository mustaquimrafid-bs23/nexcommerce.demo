# 📣 Ads Scripts & Copy Library

This folder stores all **ad copy, headlines, and campaign scripts** for the **nexCommerce** platform.

## 📁 Folder Structure

```
docs/ads/
├── README.md              ← You are here — index & guidelines
├── banners/               ← Banner ad scripts (static & animated)
├── campaigns/             ← Full campaign briefs & scripts
└── templates/             ← Reusable copy templates & formulas
```

## ✍️ Naming Convention

Use: `[campaign-name]-[format]-[variant].md`

- `summer-sale-banner-v1.md`
- `homepage-hero-cta-v2.md`
- `flash-sale-push-notification-v1.md`

## 🏷️ Standard File Frontmatter

Every ad script file should start with this metadata block:

```markdown
---
campaign: [Campaign Name]
platform: [Google Display / Meta / LinkedIn / Email / In-App]
format: [Banner / Hero / Carousel / Interstitial / Push]
audience: [Target Audience Description]
goal: [Awareness / Conversion / Retention / Engagement]
status: [Draft / Review / Approved / Live / Archived]
created: [YYYY-MM-DD]
last_updated: [YYYY-MM-DD]
---
```

## 📌 Quick Reference — Copywriting Formulas

| Formula | Structure | Best For |
|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | Long-form banners, email |
| **PAS** | Problem → Agitate → Solution | Conversion ads |
| **FAB** | Feature → Advantage → Benefit | Product ads |
| **4Cs** | Clear → Concise → Compelling → Credible | Short-form copy |

---

> **Brand Rule**: Never use the words "AI" or "A.I." in any customer-facing copy.
> Present smart features as natural conveniences: *Smart Search*, *Fit Advisor*, *Personal Stylist*.
